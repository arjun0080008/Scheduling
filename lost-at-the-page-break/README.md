# Lost at the Page Break

A cinematic, keyboard-driven version of the 29-slide M&M talk.

Everything is in one file, [`index.html`](./index.html): the slides, fonts, images and animation code. It needs no internet connection and no install. It runs from this site, from a USB stick, or by double-clicking the file.

## Presenting

Open `index.html` in Chrome or Edge, click once on the page, press **F** for full screen, then **Space**.

| Key | What it does |
|---|---|
| Space, →, ↓, Page Down, click | Next move |
| Shift+Space, ←, ↑, Page Up | Back one move |
| Home / End | First / last slide |
| a number, then Enter | Jump to that slide |
| O | All slides |
| F | Full screen |
| T | Light / dark |
| B | One press per slide instead of one press per move |
| M | Calmer motion (use on a slow computer) |
| ? | Show these keys |

There are 29 slides and 88 moves. A clicker works (it sends Page Down / Page Up).

## What to know

- The words on every slide match the source PowerPoint exactly; this was checked automatically when the file was built. Speaker notes are not included.
- The deck still shows the bracketed "to confirm" placeholders that are on the original slides.
- This repository is public. The deck describes a de-identified patient case, so check your program's rules before sharing the link.
